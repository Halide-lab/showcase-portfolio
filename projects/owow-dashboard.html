Dashboard

UI/UX DESIGN

To design a dashboard system that helps project owners, managers and employees efficiently track project status, tasks, updates and communication in one organized environment.

The design approach focused on clarity, usability and accessibility. Clean layouts, organized sections and simple navigation patterns were used to help users quickly understand project information and manage their workflow more efficiently.

Role UI/UX Design, Prototyping, Coding

Tools Figma, HTML, CSS, JS

Duration 6 weeks
